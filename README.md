# NOIRÉ Coffee-inspired Coffee Experience (Flutter)

A customized NOIRÉ Coffee-inspired redesign of the uploaded CoffeeShop UI project.

## What's changed
- Deep forest-green, cream and warm-gold visual theme.
- NOIRÉ Coffee-inspired home screen with branded header, promotional hero panel and category chips.
- Updated coffee catalogue with familiar NOIRÉ Coffee-style drink names.
- INR pricing and Indian-rupee cart/checkout display.
- Existing Provider-powered cart, favourites, product customisation, checkout, rewards and profile flows retained.

## Run locally
1. Open this folder in Android Studio.
2. Run `flutter pub get`.
3. Run `flutter run` (or select Chrome / an Android emulator).
